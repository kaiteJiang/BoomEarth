# 鲜彩漫画逐区绘制

正式漫画组件绘制要求 `工程/sponge-drawing-plan.json`，并绑定 `工程/comic-semantic-parts.json`。后者保存原图 SHA-256、原生尺寸、语义部件顺序和无损整数像素归属。缺少绘制计划或分区、可见像素未归属、尺寸或原图哈希不符时，正式编译失败。

每个可辨认物件应有独立 owner。文字只占真实字迹，不能先用文字矩形从人物或物件中挖洞。相互接触的物体沿可见轮廓分开；遮挡组合先画前景物件、再画后方表面，不臆造被挡住的部分。像素覆盖完整不等于语义分区正确，仍需逐个查看独立图层。

连通块也不等于单个物件。例如书堆、台灯、笔筒和绿植即使轮廓相接，也不能合并成一个 owner 扫描；否则会同时露出几个物件的顶部。检查遮挡依赖时，台历挡住电脑就先画台历，闹钟挡住枕头就先画闹钟，最后再补全其后的可见表面。

使用 `automation/scripts/build_comic_semantic_parts.py` 编译已审索引遮罩。输入 spec 为 `{"scenes":[{"id":"scene-01","source":"assets/source.png","mask":"assets/owners.png","parts":[...]}]}`；遮罩使用 L/P 模式，0 表示背景，1..N 对应部件。每个 part 包含 `id`、`kind`、`weight`；完整人物在先，原生文字在末。输出目录必须是项目内的新目录，保留失败版本。

运行时先在白底合成源像素，逐物件、逐连通区域规划细画笔。每个像素在笔刷首次触及时直接显现原色，笔刷也覆盖同一物件内相邻的浅色碎片。后续笔画不再改变这些像素；末帧不叠加整图补洞。与白底差不超过 3 的近白纸纹不驱动画笔。

过程检查必须覆盖每项的开始、10%、25%、50%、75%、90%、99% 和完成时，并检查已完成像素不变、下一项没有提前出现、回退跳转一致和末帧没有补色突现。另从演示 MP4 抽取中途及物件完成帧。保留当前左文右图、画手、卡片动效；原海绵运行时不迁移。

旧独立 HTML 的 polygon fallback 仅用于兼容，不能作为已修复语义分区的证据。正式漫画编译不再使用该 fallback。
