# KaterJ Video Titles

## Outcome

Create 8–12 distinct title candidates that describe the real subject and leave a useful information gap without promising anything absent from the script or video.

## Workflow

1. Write one internal sentence: audience + topic + result.
2. Use `jl-multiplatform-titles` to separate platform title, cover hook, spoken opening, and proof before expanding the candidate set.
3. Inventory defensible numbers, elapsed time, cost, comparisons, steps, artifacts, and failures.
4. Build candidates from different angles: result, pain, measured process, reversal, tutorial, comparison, or evidence.
5. Keep title, cover hook, and spoken opening separate: title explains the object and result; cover keeps one short tension point; opening begins the actual story.
6. Attach a proof segment or finished artifact to every numeric or comparative promise.
7. Rank a Top 3 for theme fit, click reason, evidence, information gap, and spoken Chinese.

## Queue behavior

For queue handoffs, write candidates and Top 3 into the handoff only; the user chooses at publishing time. Do not create `视频标题.md`. For a non-queue finished video, save a selected title only after explicit selection.

## Acceptance

- Candidates are different angles, not synonym swaps.
- Tool names appear only when they help identify the subject.
- Star counts, cost, speed, and comparisons have traceable evidence.
- Cover wording does not duplicate the title.
- No empty “震惊、重磅、炸裂、必看” language remains.
