# 上游归属与许可证边界

目标样例仓库为 [chujianyun/awesome-gpt-image2-ppt-skills](https://github.com/chujianyun/awesome-gpt-image2-ppt-skills)。它用于验证“输入一个 GitHub Skill URL，经私有解读进入洗稿和视频链路”的能力，并作为后续四种独立插画风格的来源说明。

BoomEarth 只借鉴公开 Skill 文档中表达的方法与风格定义。当前实现是项目内独立编写的 URL 解析、预算审批、Markdown 快照、哈希清单、恢复和无来源交接流程；未安装目标仓库，未执行目标仓库代码，也未复制其运行时实现到项目 Skill 目录。

该样例仓库已经完成一次获批、匿名、限额内的真实采集，验收状态为 `REAL_ACCEPTANCE_PASS`；私有 `github-skill-manifest.json` 记录许可证状态为 `UNDECLARED`。不得据此推断为 MIT、可商用或允许再分发；后续仓库状态变化也必须通过新的独立审批采集确认。
